# Комплексная динамика и теория групп

**Программа работы над первой теоремой. Версия 2.0 от 6 ноября 2026 года.**
Нагрузка: **12–15 часов в неделю**. Первый цикл: **12 учебных недель**.

Основной документ: [programme.pdf](programme.pdf), исходник —
[programme.tex](programme.tex).

Цель цикла — полное доказательство одного содержательного утверждения,
сравнение с ближайшей литературой и исследовательская записка для внешней
проверки. Первые две недели посвящены точной постановке и предшественникам.
Дальнейшая работа зависит от результата этой проверки.

Основной кандидат — конечные сертификаты включения в компоненту
орбитального приближения. **Новизна пока не установлена.** Алгоритмы
описания компонент полуалгебраических множеств уже известны; дополнительный
вопрос требуется выделить до продолжительной работы над доказательством.

Начать здесь:

1. [План двенадцати недель](first_12_weeks.md).
2. [Паспорт исследования](research_passport.md).
3. [Рабочая папка T1](research/README.md): постановка, предшественники,
   начальная схема доказательства, примеры и препятствия.
4. [Журнал](progress.csv): фактические результаты и время заполняются
   после выполнения работы.

Базовая неделя: **6 часов доказательства, 2 часа литературы по текущему
препятствию, 2 часа текста, 1 час проверок, 1 час обсуждения и журнала**.
Дополнительные три часа распределяются между доказательством и проверкой.
Обязательные параллельные курсы снимаются. Любич, Михайлов–Пасси,
Хэтчер и Милнор используются по зависимостям выбранной теоремы.

Контрольные этапы: недели **2, 4, 8 и 12**. Известная или опровергнутая
постановка получает соответствующий статус и письменное объяснение.
Двенадцатинедельный срок задаёт продолжительность попытки; получение
нового результата за этот срок заранее неизвестно.

Сборка из корня репозитория:

```bash
make -C study
```

Нужны XeLaTeX, Noto Serif и установленные UTF-8 шаблоны русских переносов
(`loadhyph-ru.tex`, обычно пакет `texlive-lang-cyrillic`). Локальный формат
создаётся в `study/.build/` по `tex/language.dat`; там же находятся
вспомогательные файлы. Итоговый PDF — `study/programme.pdf`.
