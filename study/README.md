# Комплексная динамика и теория групп

**Программа работы над первой теоремой. Версия 2.2 от 6 ноября 2026 года.**
Нагрузка: **12–15 часов в неделю**. Первый цикл: **12 учебных недель**.

Основной документ: [programme.pdf](programme.pdf), исходник —
[programme.tex](programme.tex).

Цель цикла — полное доказательство одного содержательного утверждения,
сравнение с ближайшей литературой и исследовательская записка для внешней
проверки. Первые две недели посвящены точной постановке и предшественникам.
Дальнейшая работа зависит от результата этой проверки.

Основное направление — **бисеты**. Результат B1-R теперь доказан полностью
и снят с роли основного исследовательского кандидата: формула рангов
получается элементарно из описания первого стабилизатора.
Самостоятельный научный вклад для неё не обоснован.

Начать с [аудита и полного доказательства, PDF](novelty_audit.pdf),
[того же текста в Markdown](research/B1_novelty_audit.md).
Следующий основной результат выбирается по
[карточке предполагаемого вклада](templates/novelty_card.md).

Для каждого кандидата требуются ближайшая теорема, попытка сведения,
точное дополнительное утверждение и пример его математической пользы.
Состояние проверки ведётся в [реестре](research/novelty_register.csv).
Новый основной кандидат пока не выбран.

[Пять первых занятий, PDF](first_days.pdf),
[Markdown](research/B1_first_days.md) сохранены как подробный образец
работы с гипотезой, контрпримером, определениями и доказательством.
Исторические промежуточные статусы помечены отдельно.
Точные вычисления и подъём пар секций проверяются командой:

```bash
python3 study/research/b1_compute.py --check
```

В первые две недели: **4 часа близких теорем, 3 часа попыток сведения,
3 часа формулировки и сравнения, 1 час примеров, 1 час обсуждения и журнала**.
После выбора основного результата: 6 часов доказательства, 2 — литературы,
2 — текста, 1 — проверок, 1 — обсуждения. Дополнительные 3 часа
распределяются по текущему препятствию.

Контрольные этапы: недели **2, 4, 8 и 12**. Известная или опровергнутая
постановка получает соответствующий статус и письменное объяснение.
Двенадцатинедельный срок задаёт продолжительность попытки; получение
нового результата за этот срок заранее неизвестно.

Сборка из корня репозитория:

```bash
make -C study
```

Нужны Pandoc, XeLaTeX, Noto Serif и установленные UTF-8 шаблоны русских переносов
(`loadhyph-ru.tex`, обычно пакет `texlive-lang-cyrillic`). Локальный формат
создаётся в `study/.build/` по `tex/language.dat`; там же находятся
вспомогательные файлы. Итоговые PDF — `study/programme.pdf`, `study/first_days.pdf`
и `study/novelty_audit.pdf`.
Исходник разбора — Markdown; Pandoc создаёт промежуточный LaTeX в `.build/`.
