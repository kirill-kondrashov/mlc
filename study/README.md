# Бисеты: план первой статьи

Версия 3.1 от 7 ноября 2026 года. **12–15 часов в неделю.**
Цель — первая статья с содержательным новым результатом и полным
доказательством.

Начать с [короткого плана, PDF](programme.pdf).
В нём: итог проверки кандидата, следующий шаг и порядок работы над статьёй.

- [Текущая задача](research_passport.md).
- [Порядок первых двенадцати недель](first_12_weeks.md).
- [Источники и нужные разделы](references.md).
- [Карточка сравнения с литературой](templates/novelty_card.md).
- [Журнал](progress.csv).

Подробные математические примеры сохранены отдельно:
[первые занятия](first_days.pdf), [завершённая B1-R](novelty_audit.pdf),
[полный аудит B2-N](b2_audit.pdf).
B2-N вычислена для всех глубин и сведена к известным результатам.
Оба кандидата закрыты как основные; следующий результат ещё выбирается.

Сборка всех PDF:

```bash
make -C study
```

Нужны Pandoc, XeLaTeX, Noto Serif и русские переносы
(`loadhyph-ru.tex`). Вспомогательные файлы находятся в `.build/`.
Исходник плана — [publication_plan.tex](publication_plan.tex);
подробные разборы собираются из Markdown в [research/](research/README.md).
