# T1: примеры

## E0 — проверка формата на простом входе

**Статус:** стартовый пример, подготовленный вместе с программой;
научная новизна не заявляется.

Возьмём `x=0`, `N=L=1`, `δ=1/8`, `r=1/2`. Поскольку `P₀=0`, `P₁(c)=c`,
имеем `O₁ = closedBall(0,2)`,

\[
K=\overline B(0,1/8),\qquad H=\overline B(0,1/2).
\]

Положим `D=Q=[−1/8,1/8]²`; разбиение состоит из одной включённой клетки.
Для `z ∈ Q`

\[
|z|^2\le (1/8)^2+(1/8)^2=1/32<1/4=r^2.
\]

Поэтому `Q ⊆ H`; также `0 ∈ Q` и `K ⊆ Q`. Граф состоит из одной корневой
вершины. Все условия L0 выполнены. Интервальный тест для `g_c` и `g₁`
даёт нижнюю границу `4−1/32`, для `b_r` — `1/4−1/32`; для `g₀` — `4`.
Все границы положительны. Условие на рёбра пусто.

Этот пример проверяет нормировки и возможность построения свидетеля.
Он не устанавливает исследовательскую ценность кандидата T1.
