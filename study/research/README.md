# Рабочая папка первой теоремы

Основное направление — **бисеты и групповые факторы**.
Кандидат **B1-R**: формула рангов абелевых портретов стабилизаторов уровней
для заданной рекурсии над свободной группой. **Новизна не установлена.**

Начать с [разбора первых пяти занятий, PDF](../first_days.pdf) или
[того же текста в Markdown](B1_first_days.md).
В нём действительно выполнены начальные доказательства и вычисления;
распределение по дням моделирует организацию работы.

- [B1_statement.md](B1_statement.md) — точное утверждение и доказанная база.
- [B1_prior_art.md](B1_prior_art.md) — источники и состояние их проверки.
- [b1_compute.py](b1_compute.py) — воспроизводимые вычисления.
- [B1_calculations.json](B1_calculations.json) — точные конечные результаты.

Проверка из корня репозитория:

```bash
python3 study/research/b1_compute.py --check
```

Фактические занятия пользователя заполняются отдельно в
[журнале](../progress.csv). Подготовленный образец не считается
автоматически выполненной неделей.
