# Рабочая папка: бисеты и проверка научного вклада

**Первый результат B1-R доказан полностью и снят с роли основного
исследовательского кандидата. Новый основной кандидат пока не выбран.**

Начать с [аудита новизны и доказательства, PDF](../novelty_audit.pdf),
[тот же текст в Markdown](B1_novelty_audit.md).
Формула `r_m=2^m+1` оказалась элементарным следствием описания первого
стабилизатора. Точная публикация этой формулы пока не установлена;
самостоятельный научный вклад не обоснован.

- [B1_statement.md](B1_statement.md) — законченный результат и его статус.
- [B1_prior_art.md](B1_prior_art.md) — конкретные предшественники.
- [novelty_register.csv](novelty_register.csv) — отдельные статусы доказательства,
  предполагаемой новизны и решения по задаче.
- [Карточка вклада](../templates/novelty_card.md) — обязательная запись
  перед выбором следующего основного утверждения.

## Пример первых рабочих действий

[Пять занятий, PDF](../first_days.pdf),
[исходный текст](B1_first_days.md). Сохранены первоначальная гипотеза,
контрпример, исправленная конструкция, начальные доказательства
и конечные вычисления. Промежуточные статусы отмечены как исторические.

[Скрипт](b1_compute.py), [точные данные](B1_calculations.json).
Проверка из корня репозитория:

```bash
python3 study/research/b1_compute.py --check
```

Фактические занятия пользователя ведутся в [журнале](../progress.csv).
Подготовленные доказательства не считаются автоматически освоенными.
