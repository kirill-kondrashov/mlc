## Текущий кандидат B3

[Постановка, PDF](../b3_candidate.pdf), [Markdown](B3_candidate.md).
Явный конечный глобальный аттрактор кривых для mating базилики и кролика,
с доказательством попадания всех обратных образов любой кривой.
Известные частные классы проверены; критерий Pilgrim исключён
доказательством `ρ(φ_F) ≥ 1`. Основное утверждение не доказано.

[Полный аудит, PDF](../b3_audit.pdf), [Markdown](B3_novelty_audit.md).
Доказаны единственность существенной компоненты, сюръективность
виртуального эндоморфизма и препятствие для высоты только на разбиениях.
[Точные данные аудита](B3_audit_data.json), [скрипт](b3_audit_compute.py).

```bash
python3 study/research/b3_audit_compute.py --check
```

[Начальные точные данные](B3_initial_data.json), [скрипт](b3_compute.py).
Вычислены критические орбиты, слои и триангуляция. Полная рекурсия
бисета и аттрактор пока не вычислены.

