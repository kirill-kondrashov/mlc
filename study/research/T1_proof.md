# T1: начальная схема доказательства

**Статус:** вспомогательная бумажная лемма L0 подготовлена вместе с программой.
Научная новизна не заявляется. Проверяющий алгоритм в коде не реализован.
Основная теорема существования или оценки пока отсутствует.

## Формат начального свидетеля

Входы и множества `K,H` определены в [T1_statement.md](T1_statement.md).
Положим

\[
D=[\Re x-\delta,\Re x+\delta]\times
  [\Im x-\delta,\Im x+\delta].
\]

Свидетель содержит:

1. Конечное прямоугольное разбиение `D` рациональной сеткой. Клетки
   замкнуты, их объединение равно `D`; пересечения по границам допускаются.
2. Для каждой клетки — метку «исключена» или «включена».
3. Для исключённой клетки — точную интервальную оценку, доказывающую
   нарушение хотя бы одного неравенства определения `K` на всей клетке.
4. Конечное непустое семейство непустых замкнутых рациональных
   прямоугольников `Q_j`. Оно содержит все включённые клетки; допускаются
   дополнительные соединяющие прямоугольники. Для каждого проверено
   `Q_j ⊆ H`.
5. Корневой индекс `j₀` с `x ∈ Q_{j₀}` и конечное дерево на индексах `j`,
   охватывающее все индексы. Для каждого ребра `(j,k)` проверено
   `Q_j ∩ Q_k ≠ ∅`.

Для рациональных прямоугольников непустота пересечения проверяется
сравнением концов двух пар отрезков. Одна лишь близость клеток не даёт ребра.

## Как сделать числовую часть конечной

Неравенства записываются через действительные многочлены:

\[
g_c(z)=4-|z|^2,\quad g_n(z)=4-|P_n(z)|^2,\quad
b_t(z)=t^2-|z-x|^2.
\]

Для включения `Q ⊆ H` достаточно вычислить точные рациональные
интервальные включения значений `g_c,g_0,…,g_N,b_r` и проверить,
что их нижние концы неотрицательны. Для исключения `Q ∩ K = ∅`
достаточно, чтобы у одного из `g_c,g_0,…,g_L,b_δ` верхний конец
интервала был строго отрицателен.

Интервалы строятся рациональными операциями по выражению многочлена
или рекурсии. Отдельная вспомогательная обязанность — доказать
корректность операций и включение всех действительных значений.
Неуспешный тест возвращает «этого свидетеля недостаточно».

## Лемма L0: корректность геометрической схемы

**Утверждение.** Если выполнены пункты 1–5, то

\[
x\in H,\qquad K\subseteq\operatorname{Comp}_x(H).
\]

**Доказательство.** Пусть `U = ⋃_j Q_j`. Из пункта 4 следует `U ⊆ H`,
из пункта 5 — `x ∈ U`. В частности, `x ∈ H`.

Каждый `Q_j` выпуклый и непустой, следовательно, связен. Упорядочим
вершины конечного корневого дерева так, чтобы родитель каждой вершины
стоял раньше неё: например, по расстоянию от корня. Объединение начинается
с `Q_{j₀}`. При добавлении каждой следующей клетки её пересечение
с клеткой родителя непусто. Объединение двух связных множеств с непустым
пересечением связно; индукция по числу вершин показывает, что `U` связно.

Для `z ∈ K` из `|z−x| ≤ δ` следуют обе координатные оценки, поэтому
`z ∈ D`. По пункту 1 точка лежит хотя бы в одной клетке разбиения.
Эта клетка не может быть исключённой: пункт 3 противоречил бы `z ∈ K`.
Следовательно, она включена и содержится в семействе пункта 4.
Значит, `z ∈ U`. Получили `K ⊆ U`.

Связное подмножество `U ⊆ H`, содержащее `x`, лежит в связной компоненте
`x` в `H`. Поэтому `K ⊆ U ⊆ Comp_x(H)`. □

Доказательство работает и при пустом `K`; наличие корневой клетки
по-прежнему необходимо для вывода `x ∈ H`.

## Что L0 оставляет для основной теоремы

- Выбрать непустой содержательный класс входов и независимые условия `R`.
- Доказать существование свидетеля такого формата при этих условиях
  либо установить точное препятствие.
- Для количественной версии получить границу размера/глубины и сравнить
  её с известными алгоритмами.
- Проверить, что дополнительный результат выходит за элементарную
  аргументацию L0 и известные полуалгебраические методы.

Наличие положительного геометрического запаса может помочь построению,
но само утверждение о его достаточности также требует проверки литературы.
