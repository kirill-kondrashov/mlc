# Текущая задача для первой статьи

7 ноября 2026 года. Направление — бисеты. **B3 выбран для двухнедельной
проверки метода.** Нагрузка — 12–15 часов в неделю.

## Предполагаемый результат B3

Для `F(z)=(z²+λ)/(z²−1)`, `λ=(1+i√3)/2`, построить явный конечный
глобальный аттрактор существенных простых кривых на сфере с пятью
посткритическими точками. Нужны список классов, все переходы внутри
него и доказательство попадания всех обратных образов любой кривой.
Теорема пока не доказана.

[Постановка и первое вычисление, PDF](b3_candidate.pdf),
[Markdown](research/B3_candidate.md), [короткий план](programme.pdf).

## Что уже проверено

- Точные критические орбиты, слои над посткритическим множеством и
  триангуляция для нормальных координат кривых.
- Теорема Bartholdi–Dudko–Pilgrim о четырёх точках не применяется.
- Все итерации исключены из проверенных полиномиальных, критически
  неподвижных случаев и склеек двух полиномов по Wu (2026v2).
- Известная инвариантная кривая из Bonnot–Braverman–Yampolsky отделена
  от требуемого утверждения о всех кривых.

Это исключает указанные прямые сведения. Применимость критерия
Pilgrim через сжатие виртуального эндоморфизма группы классов
отображений ещё нужно проверить. Полная рекурсия бисета и сам
аттрактор пока не вычислены. Новизна не объявляется установленной
для всей литературы; точные границы сравнения приведены в постановке.

## Следующие действия

1. Выбрать пути и получить полную рекурсию бисета над `F₄`.
2. Реализовать подъём простых кривых и проверить известный экватор.
3. Проверить критерий Pilgrim и существующие вычисления для этой карты.
4. Доказать формулу подъёма одного семейства с произвольным числом твистов.

Контроль через две недели: рекурсия, пробный граф переходов и формула
для бесконечного семейства. Для доказательства глобального притяжения
предстоит построить убывающую высоту на всех кривых.
Внешнего отзыва пока нет.
