# M1: immediate research task

8 November 2026. [Overall status](../README.md), [statements](research/MLC_bridge.md).
**First-paper goal:** a new MLC parameter class allowing growing return losses
with a divergent accumulated budget.

Already in Lean: the lower-bound recurrence, linear loss control,
harmonic divergence, shrinking, and connected neighborhoods.
`CandidateSystem.admissible` still leaves the genuine dynamical class
unspecified. No instances of `Realization` or `Coverage` have been constructed.

Next written results:

1. Define admissibility using genuine puzzle pieces, first returns,
   local degrees, and collars. Give each `ReturnBudget` quantity its geometric meaning.
2. Prove the parameter separation estimate on a first unbounded family;
   state all phase–parameter losses.
3. Compare with the Covering Lemma, published molecule conditions,
   unbounded satellite results, and the 2025–2026 papers.
4. Specify the exact published class and exhibit a parameter outside it.
   The numerical `harmonicBudget` example does not meet this requirement.

Until these four results are obtained, neither publication novelty nor an
extension of the parameter range is claimed. Dudko's problems provide a map
for comparison, not premises of M1. `Coverage` concerns full MLC;
the first paper needs realization and an extension on a selected subclass.
