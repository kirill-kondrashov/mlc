# Паспорт исследовательского кандидата

Версия 1: 2026-11-06. **Статус: предварительная постановка; новизна не установлена.**

## Рабочее направление

Геометрические критерии локальной связности и проверяемые конечные
аппроксимации в комплексной динамике. По умолчанию выбирается ветка A из
программы. Альтернатива после пилота — конечный посткритический тип и бисеты.

## Результаты проекта

- `Mlc/ParameterComponentApproximation.lean`: достаточность `UniformOuterBuffer`.
- `Mlc/FiniteComponentCriterion.lean`: конечное покрытие с полем `control`,
  которое само ещё содержит бесконечные кванторы и включение в компоненту.
- `Mlc/GreenSublevelIntersectionCounterexample.lean`: формальное отрицание
  старого универсального утверждения.
- `Mlc/Literature/ModelAudit.lean`: препятствия для модели гауссовой площади.
- `Mlc/FiniteTrappingRegions.lean`: конечные объединения ловушек,
  устойчивость при запасе, принадлежность параметров внутренности M.

Для включения в рукопись установить авторство, даты и источники по истории проекта.

## Предварительный вопрос

Для **явно ограниченного класса геометрических конфигураций** построить
проверяемый конечный сертификат включения

`O_L ∩ closedBall(x, δ) ⊆ component_x(O_N ∩ closedBall(x, r))`.

Сначала фиксируются `x, N, L, r, δ`. Доказать:

1. Корректность формата сертификата.
2. Существование сертификата при конкретных геометрических запасах.
3. Если возможно — зависимость глубины и точности от этих запасов.

Переход к `∀ x ∈ M, ∀ ε > 0, ∃ δ,r, ∀ N, ∃ L` — самостоятельная
математическая задача.

- [ ] Геометрическая лемма, связывающая конечную проверку с настоящей компонентой.
- [ ] Содержательный пример за пределами простой проверки внутренней точки M.
- [ ] Результат о границе метода: где нет строгого запаса или завершаемости.

## Проверка новизны

| Вопрос | Пока установленный ответ |
| --- | --- |
| Ближайшая существующая теорема | Нужно найти и разобрать точное доказательство |
| Что добавлено к ней | Пока не зафиксировано |
| Почему это не прямое следствие | Пока не установлено |
| Что уже сделано в данном репозитории | Перечислено выше; требуется история авторства |
| Кто проверил постановку извне | Пока никто не указан |
| Минимальный отрицательный тест | Одной близости клеток недостаточно для связности; локальная связность предела не даёт BUF для произвольных внешних приближений |

## Пилот на восемь недель после выбора темы

- Недели 1–2: один точный класс и два тестовых примера; поиск предшественников.
- Недели 3–4: одна геометрическая лемма и полный бумажный аргумент.
- Недели 5–6: проверка формата сертификата на примере, при необходимости Lean.
- Недели 7–8: независимая проверка и короткая законченная записка.

Результат пилота — лемма, контрпример или доказанное ограничение
с полным аргументом и решением о следующем этапе.

## Обязательное внешнее обсуждение

Подготовить 1 страницу постановки, 2–4 страницы ключевого доказательства и
один вопрос: «Какой ближайший известный результат делает эту постановку
стандартной или указывает содержательное ограниченное усиление?»
