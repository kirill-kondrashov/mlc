# Research packages

These packages contain mathematical notes, calculations and their own PDF
builds. They are independent of the Lean library in `Mlc/`.

- [pilgrim-bisets](pilgrim-bisets/README.md): B3, the global curve attractor
  problem for the rabbit–Basilica mating, concerning Pilgrim's conjecture.
  The main theorem is unproved. No implication to MLC is established.

The main MLC research programme is in [study/](../study/README.md).
