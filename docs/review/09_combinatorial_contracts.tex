\section{Discrete renormalization data}

\begin{definition}[Renormalization profile]
\label{def:renormalization-profile}
A discrete renormalization profile consists of:
\[
 (\tau,p_n,\rho_n)_{n\in\N},
\]
where $\tau$ is one of the primitive, satellite, or neutral types,
$p_n\in\N$ is the relative period at level $n$, and
$\rho_n\in\N$ records the combinatorial rotation data.
\end{definition}

\begin{definition}[Bounded type]
\label{def:bounded-type}
The rotation profile $(\rho_n)$ is of bounded type if
\[
 \exists B\in\N\ \forall n,\qquad \rho_n\le B.
\]
\end{definition}

The Lean definitions make bounded type an explicit predicate:
\begin{itemize}
\item \lean{RenormalizationCombinatorics};
\item \lean{BoundedType};
\item \lean{IsBoundedTypeSatelliteProfile}.
\end{itemize}
They do not identify bounded type with a numerical picture or with bounded
periods: the rotation sequence is a separate field.
Nor do these fields yet identify the integer rotation sequence with a
marked rational rotation number or its continued-fraction data.
The current profile has one constant type label; a tower with mixed
primitive and satellite levels needs richer, level-dependent data.

\begin{definition}[Cumulative depth]
\label{def:cumulative-depth}
For a profile with periods $(p_n)$ define
\[
 d_0:=0,\qquad d_{n+1}:=d_n+p_n.
\]
\end{definition}

\begin{theorem}[Depth monotonicity]
\label{thm:depth-monotonicity}
If $p_n>0$ for every $n$, then $d_n$ is monotone.  For the period-doubling
profile $p_n=2$, one has $d_n=2n$.
\end{theorem}

The proofs are elementary arithmetic and are available as
\lean{cumulativeDepth_monotone} and
\lean{cumulativeDepth_periodDoubling}.  This separates the discrete
bookkeeping from the analytic construction of the tower.  The additive
depth is an index, not a return period in the original dynamics.

\begin{definition}[Original return period]
Given relative periods $p_n$, put
\[
 T_0=1,\qquad T_{n+1}=T_np_n.
\]
\end{definition}

\begin{proposition}[Period-doubling arithmetic]
If every $p_n=2$, then
\[
 d_n=2n,\qquad T_n=2^n.
\]
\end{proposition}

\begin{proof}
Induct on $n$, using the additive recurrence for $d_n$ and the
multiplicative recurrence for $T_n$.
\end{proof}

The second recurrence and its proof are
\leanref{Mlc/Literature/Combinatorics.lean}{relativePeriodProduct} and
\lean{relativePeriodProduct_periodDoubling}.
The period-doubling profile is tagged satellite: successive little
Julia sets meet at the marked periodic attachment point.
It is a particular bounded-combinatorics example, not the definition
of the entire Feigenbaum class.

\section{Modulus divergence}

\begin{lemma}[Uniform lower bound]
\label{lem:combinatorial-modulus-lower}
Let $(a_n)$ be a sequence of nonnegative real numbers.  If
\[
 \exists\mu>0\ \forall n,\qquad \mu\le a_n,
\]
then $\sum_n a_n$ is divergent.
\end{lemma}

\begin{proof}
The $N$-th partial sum is at least $N\mu$, so the partial sums are
unbounded.
\end{proof}

The exact Lean theorem is
\lean{not_summable_of_uniform_lower_bound}; the wrapper
\lean{not_summable_of_aPrioriBounds} applies it to
\lean{APrioriBounds}.  This is the arithmetic core shared by the principal
nest arguments in the Lyubich, Dudko--Lyubich, and Kahn--Kapiamba--Lyubich
routes.

\begin{theorem}[Finite-block arithmetic contract]
\label{thm:tower-to-puzzle-arithmetic}
Let $a_k\ge0$, let $d_n$ be nondecreasing integers, and suppose numbers
$b_n$ satisfy the exact comparison
\[
 b_n=\sum_{d_n\le k<d_{n+1}}a_k.
\]
If $b_n\ge\mu>0$ for every $n$, then $\sum_k a_k$ is not summable.
\end{theorem}

\begin{proof}
The index blocks are disjoint.  If $\sum_k a_k$ converged, every
partial sum of the $b_n$ would be bounded by that nonnegative total.
But the first $N$ terms of $(b_n)$ have sum at least $N\mu$, a
contradiction.
\end{proof}

The exact finite-block identity is an assumption of this arithmetic
theorem.  In \lean{Mlc/MoleculeToParameterShrink.lean} an instance
comes from additivity of Gaussian weighted area on disjoint frozen
differences.  The audit proves that its proposed positive lower bounds
cannot exist.  For genuine conformal moduli, serial Grötzsch gives an
inequality, generally not this identity; the source-specific analytic
comparison must be proved before invoking the arithmetic contract.
