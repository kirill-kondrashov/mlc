\subsection*{Lemma parameter\_shrink\_ax}
\textbf{Description:} The Correspondence Principle:
    If the dynamical pieces shrink to a point, the parameter pieces shrink to a point.

\textbf{Proof Description:} We analyze two cases:
    1.  \texttt{c $\in$ M}: The filled Julia set \texttt{K(c)} is connected. The dynamical pieces \texttt{P\_n} contain \texttt{0}.
        Since \texttt{0 $\in$ K(c)} and \texttt{K(c)} is connected, \texttt{K(c) $\subseteq$ P\_n} for all \texttt{n} (actually \texttt{K(c)} is the "core").
        If \texttt{⋂ P\_n = \{0\}}, then \texttt{K(c) $\subseteq$ \{0\}}, which implies \texttt{c=0}.
    2.  \texttt{c ∉ M}: The pieces eventually become empty (\texttt{dynamical\_puzzle\_piece\_empty\_of\_large\_n}),
        forcing the intersection to be empty. This case is handled by contradiction or vacuous truth
        depending on exact statement (here we show if intersection is \{0\} then parameter intersection is \{c\}).

\begin{lstlisting}[language=Lean]
lemma parameter_shrink_ax (c : ℂ) :
    (⋂ n, DynamicalPuzzlePiece c n 0) = {0} → (⋂ n, ParaPuzzlePiece n) = {c} := by

\subsection*{Structure HolomorphicMotion}
\textbf{Description:} A holomorphic motion of a set E over the unit disk D.

\begin{lstlisting}[language=Lean]
structure HolomorphicMotion (E : Set ℂ) where
  /-- The motion map t ↦ z ↦ f(t, z) -/
  f : ℂ → ℂ → ℂ
  /-- At time 0, it is the identity -/
  h_zero : ∀ z ∈ E, f 0 z = z
  /-- For each fixed time in the unit disk, it is injective on E -/
  h_inj : ∀ t ∈ Metric.ball 0 1, Set.InjOn (f t) E
  /-- For each fixed z in E, it is holomorphic in time on the unit disk -/
  h_holo : ∀ z ∈ E, DifferentiableOn ℂ (fun t ↦ f t z) (Metric.ball 0 1)
\end{lstlisting}

\subsection*{Axiom slodkowski\_theorem}
\textbf{Description:} Slodkowski's Theorem (Generalized Lambda Lemma).
    "Every holomorphic motion f : D × E $\to$ $\mathbb{C}$ of an arbitrary subset E of $\mathbb{C}$ can be
    extended to a holomorphic motion F : D × $\mathbb{C}$ $\to$ $\mathbb{C}$ (that is F|D×E = f) of $\mathbb{C}$,
    parametrized by the same unit disc D."
    See: [Slodkowski, Holomorphic motions and polynomial hulls, Theorem 1.3] <https://www.ams.org/journals/proc/1991-111-02/S0002-9939-1991-1037218-8/>
    Local Reference: \texttt{refs/S0002-9939-1991-1037218-8.pdf}

\begin{lstlisting}[language=Lean]
axiom slodkowski_theorem {E : Set ℂ} (h : HolomorphicMotion E) :
    ∃ H : HolomorphicMotion Set.univ,
      ∀ t ∈ Metric.ball 0 1, ∀ z ∈ E, H.f t z = h.f t z
\end{lstlisting}

    This axiom provides the existence of a holomorphic motion on the boundary of the puzzle piece,
    which serves as the input for Slodkowski's Extension Theorem.

    **Definition** [Slodkowski, p. 347]:
    "A holomorphic motion of E in C, parametrized by the unit disc D, is a map f: D × E $\to$ C
    such that (a) for any fixed w $\in$ E, the map z ↦ f(z, w): D $\to$ C is holomorphic;
    (b) for any fixed z $\in$ D, the map w ↦ f(z, w) is one-to-one; and (c) f₀ is the identity map on E."

    In this context:
    *   \texttt{E} is the boundary of the puzzle piece (or a neighborhood of it).

\subsection*{Theorem para\_puzzle\_piece\_open}
\textbf{Description:} Parameter puzzle pieces are open sets.
    This is proved using Slodkowski's Theorem which ensures that the holomorphic motion
    of the dynamical plane implies structural stability of open sets in the parameter plane.

\textbf{Proof Description:} 1.  We invoke \texttt{puzzle\_boundary\_motion\_exists} (axiom) to obtain a holomorphic motion \texttt{h}
        of the boundary of the puzzle piece over a small disk \texttt{D} in parameter space.
    2.  We apply **Slodkowski's Theorem** (\texttt{slodkowski\_theorem}) to extend this motion to a
        holomorphic motion \texttt{H} of the entire plane.
    3.  The existence of this extension implies that the combinatorics of the puzzle piece are stable.
        Specifically, for any parameter \texttt{c'} in the disk \texttt{D}, the point \texttt{0} remains inside the
        puzzle piece if it started there. This shows \texttt{ParaPuzzlePiece n} contains a neighborhood \texttt{D},
        hence is open.

\subsection*{Theorem para\_puzzle\_piece\_inter\_mandelbrot\_connected}
\textbf{Description:} Parameter puzzle pieces intersected with the Mandelbrot set are connected.

\textbf{Proof Description:} The set \texttt{P\_n $\cap$ M} corresponds to parameters \texttt{c $\in$ M} such that \texttt{c} (or \texttt{0}? via correspondence)
    is in the dynamical piece \texttt{D\_n(c)}.
    Since \texttt{c $\in$ M}, the filled Julia set \texttt{K(c)} is connected (Douady-Hubbard).
    The dynamical piece \texttt{D\_n(c)} is defined by level sets of Green's function, which surrounds \texttt{K(c)}.
    Since \texttt{0 $\in$ K(c) $\subseteq$ D\_n(c)}, the condition is satisfied for all \texttt{c $\in$ M}.
    So \texttt{P\_n $\cap$ M} is effectively just \texttt{M}?
    (The proof shows \texttt{M $\subseteq$ P\_n} implies \texttt{P\_n $\cap$ M = M}, and \texttt{M} is connected).
