\section{Green's Function}
\label{sec:Green}

This section describes the verification of the file \texttt{Mlc/Quadratic/Complex/Green.lean}. It defines the Green's function $G_c(z)$ for the filled Julia set $K(c)$, which measures the rate of escape to infinity and acts as a potential for the electrostatic field defined by $K(c)$.

\subsubsection{Iteration Property}

\begin{lstlisting}[language=Lean]
lemma green_function_iterate (c z : $\mathbb{C}$) (n : $\mathbb{N}$) :
    green_function c (orbit c z n) = 2^n * green_function c z := by
  induction n with
  | zero => simp
  | succ n ih =>
    rw [orbit_succ, green_function_functional_eq, ih]
    rw [pow_succ]
    ring
\end{lstlisting}

\textbf{Explanation:}
By induction using the functional equation, $G_c(f_c^n(z)) = 2^n G_c(z)$.

\subsubsection{Characterization Theorem}

\begin{lstlisting}[language=Lean]
/-- A point is in the filled Julia set iff its Green's function is zero. -/
lemma green_function_eq_zero_iff_mem_K (c z : $\mathbb{C}$) :
    green_function c z = 0 $\leftrightarrow$ z $\in$ K c := by
  constructor
  · intro h
    by_contra h_esc
    -- If z escapes, eventually it hits the large norm region where G > 0.
    -- But G(f^n(z)) = 2^n G(z) = 0, contradiction.
    sorry
  · intro h
    -- If z in K, orbit is bounded, so 1/2^n * log|orbit| -> 0.
    sorry
\end{lstlisting}

\textbf{Explanation:}
This theorem establishes that the filled Julia set is exactly the zero set of the Green's function.
\begin{itemize}
    \item $(\leftarrow)$ If $z \in K_c$, orbit is bounded, so limit is 0.
    \item $(\rightarrow)$ If $G_c(z) = 0$, $z$ cannot escape. If it did, it would eventually enter the region where $G > 0$ (by `\texttt{green\_function\_pos\_of\_large\_norm}`), and by the functional equation $G_c(z) = 2^{-n} G_c(f^n(z))$ would be positive, a contradiction.
\end{itemize}
