\section{Basic Definitions}
\label{sec:Basic}

This section establishes the fundamental definitions for the dynamics of quadratic polynomials.

\subsection{Quadratic Family: \texttt{fc}}

We consider the family of quadratic polynomials parameterized by $c \in \mathbb{C}$.

\textbf{Definition}: The quadratic map $f_c: \mathbb{C} \to \mathbb{C}$ is defined by $f_c(z) = z^2 + c$.

\begin{lstlisting}[language=Lean]
def fc (c : $\mathbb{C}$) : $\mathbb{C}$ $\to$ $\mathbb{C}$ := fun z => z^2 + c
\end{lstlisting}

The orbit of a point $z_0$ is the sequence of iterates $z_{n+1} = f_c(z_n)$.
\[ \text{orbit}(c, z_0, n) = f_c^{\circ n}(z_0) \]

\subsection{Julia and Mandelbrot Sets}

\textbf{Definition}: The \emph{Filled Julia Set} $K_c$ is the set of points with bounded orbits under $f_c$.
\[ K_c = \{ z \in \mathbb{C} \mid \exists M, \forall n, |f_c^{\circ n}(z)| \le M \} \]

\begin{lstlisting}[language=Lean]
def K (c : $\mathbb{C}$) : Set $\mathbb{C}$ := { z | boundedOrbit c z }
\end{lstlisting}

\textbf{Definition}: The \emph{Mandelbrot Set} $\mathcal{M}$ is the set of parameters $c$ for which the critical point $0$ has a bounded orbit (i.e., $0 \in K_c$).
\[ \mathcal{M} = \{ c \in \mathbb{C} \mid 0 \in K_c \} \]

\begin{lstlisting}[language=Lean]
def MandelbrotSet : Set $\mathbb{C}$ := { c | boundedOrbit c 0 }
\end{lstlisting}

\subsection{Basic Properties}

We define a standard "escape radius" $R(c) = \max(2, |c| + 1)$.
It is a standard result that if $|z| > R(c)$, then the orbit of $z$ escapes to infinity.

We also accept as axioms the connectivity of the Mandelbrot set and the connectivity of $K_c$ for $c \in \mathcal{M}$ (Douady-Hubbard).
