\subsection*{Theorem yoccoz\_theorem}
\textbf{Description:} Yoccoz's Theorem: Divergence of moduli implies point intersection.

\textbf{Proof Description:} *   If \texttt{c $\in$ M}: We apply **Grötzsch's criterion** to the nested sequence of dynamical puzzle pieces.
        These pieces contain 0 and are connected. The divergence of the moduli of the annuli between
        them forces the intersection of the pieces to be a single point \texttt{\{0\}}.
    *   If \texttt{c ∉ M}: The orbit of 0 escapes. For large enough \texttt{n}, the potential level \texttt{1/2\^{}n}
        is smaller than \texttt{G(0)}, so \texttt{0} is no longer in the puzzle piece (which is defined by \texttt{G(z) < 1/2\^{}n}).
        Thus, the puzzle pieces eventually become empty. This would imply the sum of moduli is finite
        (sum of zeros), contradicting the divergence hypothesis. Thus, this case is impossible under
        the assumption of divergence.

\begin{lstlisting}[language=Lean]

    ¬ (Summable fun n => modulus (PuzzleAnnulus c n)) →
    (⋂ n, DynamicalPuzzlePiece c n 0) = {0} := by
\end{lstlisting}
