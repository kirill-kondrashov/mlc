\subsection*{Lemma para\_puzzle\_piece\_basis\_induced}
\textbf{Description:} If parameter pieces shrink to a point, they form a basis of neighborhoods for c in the Mandelbrot set.

\textbf{Proof Description:} Since the intersection of all parameter pieces \texttt{ParaPuzzlePiece n} is exactly \texttt{\{c\}},
    for any open neighborhood \texttt{U} of \texttt{c}, there must be some \texttt{n} such that \texttt{ParaPuzzlePiece n $\subseteq$ U}.
    This uses the compactness argument implicit in the "shrink to point" property for nested compact sets
    (or similar topological argument). Here we formalize it by showing \texttt{M $\cap$ P\_n} eventually lies in \texttt{U}.

\subsection*{Lemma lc\_at\_of\_shrink}
\textbf{Description:} If parameter pieces shrink to a point, M is locally connected at c.

\textbf{Proof Description:} We construct a basis of connected neighborhoods for \texttt{c}.
    1.  The parameter pieces \texttt{P\_n} are open (by \texttt{para\_puzzle\_piece\_open}).
    2.  Their intersection with \texttt{M} is connected (by \texttt{para\_puzzle\_piece\_induced\_connected}).
    3.  They shrink to \texttt{\{c\}} (hypothesis).
    4.  Therefore, for any neighborhood \texttt{U}, we can find a \texttt{P\_n} inside it. \texttt{P\_n $\cap$ M} serves
        as the connected neighborhood of \texttt{c} contained in \texttt{U}, proving local connectivity.
